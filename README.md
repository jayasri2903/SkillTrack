# SkillTrack — Learning Progress Tracker

A React-based web application that helps users organize learning tasks, track completed topics, and monitor their daily learning goals.

## Features

- **Task Management:** Add, edit, and delete learning tasks.
- **Topic Tracking:** Organize topics and mark them as completed.
- **Progress Dashboard:** View total, completed, and pending topics with overall progress.
- **Daily Learning Goals:** Set a daily target and track completion.
- **Due Dates:** Assign deadlines and identify overdue or upcoming tasks.
- **Search:** Find tasks by name.
- **CSV Export:** Download task details as a CSV file.
- **Persistent Storage:** Save tasks and learning progress using browser localStorage.
- **Responsive Design:** Use the application on desktop and mobile screens.
- **No Login Required:** Open and use the application directly.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- Browser localStorage

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open http://localhost:3000 in your browser.

## Data Storage

SkillTrack stores tasks and progress in the browser's localStorage. Data is specific to the browser and device and may be lost if the site's stored data is cleared.
